DocExplorer User Help

This guide follows the exact structure of the main menu and all context menus in the supplied DocExplorer source. Each menu item has a separate unit and an animated visual demonstration.

Tip: right-click an animated image to pause it by opening it in a separate browser tab, or revisit the section to replay it.

File menu

Scan

Open the scanner window, choose a device and acquire pages.

Open

Open the selected folder or file with the associated action.

Rename

Rename one selected file or folder.

New folder

Create a folder in the current location.

Refresh

Reload the tree and file list. Shortcut: F5.

Print

Open DocExplorer's print form for the selected file. Shortcut: Ctrl+P.

Copy

Put the selected files or folders on the clipboard. Shortcut: Ctrl+C.

Cut

Mark the selected files or folders to be moved. Shortcut: Ctrl+X.

Paste

Copy or move clipboard items into the current folder. Shortcut: Ctrl+V.

Remove to Recycle Bin

Move selected items to the Windows Recycle Bin. Shortcut: Ctrl+D.

Delete permanently

Delete selected items without moving them to the Recycle Bin. Shortcut: Shift+Del.

Add to archive

Create an archive from the selected files or folder.

Extract from archive here

Extract an archive into the current folder.

Extract from archive into

Create a named destination folder and extract the archive into it.

Options

Choose language, preview, interface and other application settings.

Exit

Save the application state and close DocExplorer.

Navigation menu

Back

Return to the previous location in navigation history.

Forward

Go to the next location in navigation history.

Up

Open the parent folder of the current location.

Add to Favorites

Add the selected folder to the Favorites pane.

Remove from Favorites

Remove the selected folder from Favorites.

Search in files

Open the search form and search by name, contents and filters.

Document menu

Import pages from file

Append pages from another supported file to the current PDF.

Import pages from scanner

Scan pages and append them to the current PDF.

Export pages

Export selected PDF pages to a new file.

Save

Write pending PDF edits to the current file.

Cancel changes

Discard pending PDF edits and reload the saved document.

Zoom in

Increase the preview scale.

Zoom out

Decrease the preview scale.

Show 1 page wide

Fit one page to the preview width.

Show 2 pages wide

Arrange two pages in each preview row.

Show 1 page tall

Fit a complete page vertically in the preview.

Manual scale

Use the zoom controls instead of an automatic fit mode.

Rotate all left

Rotate every PDF page 90 degrees counter-clockwise.

Rotate left

Rotate the selected PDF page or image counter-clockwise.

Rotate right

Rotate the selected PDF page or image clockwise.

Rotate all right

Rotate every PDF page 90 degrees clockwise.

Move page

Move a PDF page to a new position.

Remove page

Remove the selected page from the PDF.

Adjust page width

Make the current PDF page widths consistent.

Optimize

Reduce the size of the current PDF while preserving usable quality.

Optimize all PDF files

Optimize a selected PDF or every PDF in a selected folder.

Adjust page width in all PDF files

Normalize page widths in a selected PDF or folder of PDFs.

Help menu

App manual

Open this animated, menu-structured Help. Shortcut: F1.

About

Show DocExplorer version and application information.
