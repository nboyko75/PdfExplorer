目次

1. DocExplorer について

DocExplorer は、文書の検索、表示、操作に特化した Windows 用ファイルエクスプローラーです。フォルダーツリー、お気に入り、Windows ショートカット、詳細なファイル一覧、プレビューを備え、アプリ内で PDF を編集できます。

名前、種類、サイズ、更新日時を確認し、PDF、画像、テキスト、HTML、対応する Office 文書を表示できます。マスク、正規表現、日付、サイズを使って名前や内容を検索できます。PDF の編集は一時的に保持され、保存または取り消せます。コピー、切り取り、貼り付け、名前変更、削除、圧縮、展開、スキャン、印刷にも対応し、表示言語は 11 言語です。

Office のプレビューと印刷には互換性のある Microsoft Office が必要です。スキャンには Windows Image Acquisition（WIA）を使います。アーカイブの展開はインストール済みツールに依存します。

2. 使い始める

DocExplorer を起動すると、ウィンドウサイズ、分割位置、言語、最後のフォルダー、お気に入り、多くのダイアログ設定が復元されます。

ツリーでフォルダーを選ぶか、アドレスバーにパスを入力して Enter を押します。中央の一覧でファイルを選ぶと、プレビューが有効で形式が対応している場合、右側に表示されます。ダブルクリックでフォルダーに入るか、関連付けられた Windows アプリでファイルを開きます。分割線をドラッグして幅を調整します。「ファイル > オプション」で言語とプレビュー/PDF の設定を変更します。

PDF ページの編集はメモリ上で保持されます。「保存」でディスクに書き込み、「キャンセル」で破棄します。

3. メインウィンドウ

「戻る」「進む」は履歴を移動します。「検索」はファイル検索を開きます。「終了」は未保存の PDF 変更を処理してから終了します。アドレスバーにはファイルまたはフォルダーのパスを入力できます。「隠し項目」は隠しファイルの表示を切り替えます。

ファイル一覧のツールバーにはスキャン、開く、上へ、新しいフォルダー、印刷、コピー、切り取り、貼り付け、名前変更、ごみ箱へ移動があります。「フィルター」は現在の一覧を絞り込み、内容検索とは別の機能です。列見出しで並べ替え、ダブルクリックで開きます。

4. ファイルとフォルダーの移動

左側のツリーはフォルダー階層を表示します。矢印で展開し、フォルダーを選んで読み込み、「上へ」で親フォルダーを開きます。アドレスバーや履歴ボタンも利用できます。

「開く」は選択項目を開き、「プログラムから開く」は別のアプリを選択します。「更新」（F5）は現在のフォルダーと関連ツリーを再読込します。「新しいフォルダー」は現在の場所に重複しない名前で作成します。「名前変更」は名前を変更します。ドラッグ＆ドロップで対応項目をパネル間で移動・コピーできます。隠し項目は薄いアイコンで表示されます。

ファイルメニューと右クリックメニューでは、現在の選択に適用できる操作だけが有効です。

5. お気に入りと Windows ショートカット

お気に入りにはよく使うフォルダーを登録します。ナビゲーションまたは右クリックメニューで追加・削除し、矢印ボタンや行のドラッグで並べ替えます。

ショートカット欄にはデスクトップ、ドキュメント、ダウンロード、画像、音楽、ビデオ、ごみ箱を表示できます。切り替えボタンで欄を表示・非表示にし、一覧の右クリックで表示項目を選びます。

ごみ箱を選ぶと削除済み項目が一覧に表示されます。右クリックメニューから復元、完全に削除、すべて空にする操作ができます。

6. 文書のプレビュー

ファイルを選ぶと右側に表示されます。「プレビュー」は一般表示、「MS Office」は Office 変換表示を個別に有効にします。PDF のサムネイルと配置、画像の拡大縮小・回転、テキストとソースコード、内蔵ブラウザーでの HTML、対応 Office 文書を表示できます。長いテキストは応答性のため省略される場合があります。

このバージョンでは Word と Excel を HTML、PowerPoint を PDF に変換します。Microsoft Office が必要です。タブを固定すると移動中も文書を保持できます。不要なタブは固定解除または閉じます。大きな文書は設定されたページ数だけ先に読み込み、「すべて読み込む」で残りを表示します。

Office のバージョンによっては、変換中に文書ウィンドウが一瞬表示またはアクティブ化される場合があります。

7. PDF の編集

PDF と対象ページを選びます。選択ページを左右に回転するか、すべてのページを回転します。「ページを移動」は移動先の位置を指定し、「ページを削除」は編集中の文書から取り除きます。ファイルからのインポートは別の PDF のページを、スキャナーからのインポートはスキャンしたページを追加します。エクスポートは選択ページを別の PDF に保存します。

「ページ幅を調整」はスキャンしたページの幅を揃えます。「最適化」はオプションに従って画像を再圧縮します。「保存」は変更を確定し、「名前を付けて保存」は別の PDF を作成し、「キャンセル」はディスク上の状態に戻します。

最適化で画質が低下する場合があります。「ファイル > オプション」で DPI とカラー/白黒圧縮を慎重に設定し、重要な原本を保管してください。

8. ファイル内検索

検索フォルダーが検索開始位置です。「サブフォルダーを含める」で再帰検索します。マスクは空白、カンマ、セミコロンで区切ります（例：*.pdf *.txt）。Word と Excel は *.doc* と *.xls* を切り替えます。

名前と内容の条件は個別に有効化できます。両方が有効なら両方に一致する必要があります。テキストは通常検索、正規表現は Python 互換構文です。大文字小文字の区別と単語全体の一致で絞り込みます。日付とサイズの開始/終了条件は任意です。

「検索」で開始し、「停止」でキャンセルを要求します。結果をダブルクリックするとメイン画面でファイルが選択されプレビューされます。履歴、サイズ、位置、列幅が保存されます。

テキスト、ソースコード、PDF テキスト、最近の Office 形式の内容を抽出できます。OCR テキスト層のないスキャン PDF は画像内の単語で検索できません。

9. ファイル操作とアーカイブ

コピー、切り取り、ごみ箱へ移動、完全削除、アーカイブへ追加の前に、1 つ以上の項目を選択します。貼り付け先は現在のフォルダーです。ショートカットは Ctrl+C、Ctrl+X、Ctrl+V です。

アーカイブへ追加は選択ファイル/フォルダーを圧縮します。「ここに展開」は現在のフォルダーに展開し、「展開先を指定」は保存先を作成または選択します。対応形式は補助ツールと設定によって異なります。

完全削除はごみ箱を使わず、DocExplorer では元に戻せません。確認前に選択とパスを確認してください。

10. ごみ箱

Windows ショートカットからごみ箱を開きます。削除済み項目と、Windows が提供する元のメタデータが表示されます。右クリックの「復元」で元のフォルダーに戻します。「完全に削除」は選択項目を削除し、「すべて空にする」はごみ箱全体を空にします。

元のフォルダーが存在しない場合やアクセス拒否の場合、復元に失敗することがあります。フォルダーを再作成するか適切な権限を確保し、再試行してください。

11. スキャン

「ファイル > スキャン」またはスキャナーボタンを選びます。Windows WIA ダイアログで機器に応じた入力元、色、解像度を設定します。

複数ページ文書は PDF、画像は JPEG を選びます。「複数ページ」で 1 つの PDF に続けて取り込めます。出力ファイル名と終了後に開くかを指定します。同名ファイルがある場合は上書き、番号付きコピー作成、キャンセルを選べます。

WIA 対応スキャナーと Windows ドライバーが必要です。

12. 印刷

ファイルを選び Ctrl+P または「ファイル > 印刷」を選びます。プリンター、部数、全ページまたは選択ページを指定します。ページ範囲には 1,3-5 などを使えます。「プリンター設定」で Windows のプリンタープロパティを開きます。

対応する PDF と Office 文書で指定ページを印刷できます。印刷可能な余白と倍率はドライバーおよび文書アプリに依存します。

13. オプションと言語

オプションには言語、プレビューの制限と動作、PDF の品質/DPI、詳細なカラー/白黒符号化、スキャン既定値があります。「適用」で保存します。一部の表示はすぐ変わりますが、Windows 組み込み機能が古い言語のままなら再起動してください。

対応言語：英語、ウクライナ語、ドイツ語、フランス語、スペイン語、イタリア語、ブラジルポルトガル語、日本語、韓国語、簡体字中国語、ロシア語。ヘルプは選択された表示言語で開きます。

14. キーボードショートカット

F1：ヘルプ。F5：更新。Ctrl+P：選択中/現在の文書を印刷。Ctrl+C / Ctrl+X / Ctrl+V：コピー/切り取り/貼り付け。Ctrl+D：選択項目をごみ箱へ。Shift+Delete：完全削除。Enter またはダブルクリック：開く/有効化。Ctrl+Z：対応する未保存 PDF 操作を元に戻す。

15. トラブル対処と安全な操作

プレビューが空：プレビューを有効にします。Word/Excel/PowerPoint は MS Office を有効にしてインストールを確認します。大きなファイルの変換完了後、再選択します。外部アプリで開き破損やロックを確認します。

内容検索で見つからない：フォルダー、マスク、サブフォルダーを確認します。名前と内容の両方が有効なら両方の一致が必要です。日付/サイズ制限を外して再検索します。スキャン画像には OCR テキストが必要です。

EXE でアイコンやごみ箱が異なる：DocExplorer.spec を使って画像、翻訳、マニュアルを含めてビルドします。Windows メタデータはアカウント、言語、権限で変わります。外部操作後は更新してください。

最適化、完全削除、大規模な PDF 編集の前にバックアップします。「名前を付けて保存」で原本を残します。アクセス/共有エラー時は他のアプリでファイルを閉じます。PDF 書き込みやアーカイブ展開を中断しないでください。
