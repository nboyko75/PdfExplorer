목차

1. DocExplorer 소개

DocExplorer는 문서 검색, 미리 보기 및 작업을 위한 Windows 파일 탐색기입니다. 폴더 트리, 즐겨찾기, Windows 바로 가기, 상세 파일 목록, 미리 보기 창을 제공하며 앱 안에서 PDF를 편집할 수 있습니다.

이름, 종류, 크기, 수정 날짜를 확인하고 PDF, 이미지, 텍스트, HTML 및 지원되는 Office 파일을 표시합니다. 마스크, 정규식, 날짜, 크기를 이용해 이름과 내용을 검색합니다. PDF 변경은 임시로 보관한 후 저장하거나 취소합니다. 복사, 잘라내기, 붙여넣기, 이름 변경, 삭제, 압축, 압축 풀기, 스캔, 인쇄도 제공하며 인터페이스는 11개 언어를 지원합니다.

Office 미리 보기와 인쇄에는 호환되는 Microsoft Office 구성 요소가 필요합니다. 스캔은 Windows Image Acquisition(WIA)을 사용합니다. 압축 풀기는 설치된 도구에 따라 달라집니다.

2. 시작하기

DocExplorer를 실행하면 창 크기, 구분선 위치, 언어, 마지막 폴더, 즐겨찾기 및 여러 대화 상자 설정이 복원됩니다.

트리에서 폴더를 선택하거나 주소 표시줄에 경로를 입력하고 Enter를 누릅니다. 가운데 목록에서 파일을 선택하면 미리 보기가 켜져 있고 형식을 지원할 때 오른쪽에 표시됩니다. 두 번 클릭하면 폴더를 열거나 연결된 Windows 앱으로 파일을 엽니다. 구분선을 끌어 창 영역을 조절합니다. 파일 > 옵션에서 언어와 미리 보기/PDF 설정을 선택합니다.

PDF 페이지 변경은 메모리에 보관됩니다. 저장은 디스크에 기록하고 취소는 변경을 버립니다.

3. 주 창

뒤로와 앞으로는 위치 기록을 이동합니다. 검색은 파일 검색을 엽니다. 종료는 저장하지 않은 PDF 변경을 처리한 뒤 앱을 닫습니다. 주소 표시줄에는 폴더나 파일 경로를 입력합니다. 숨김 항목은 숨겨진 파일의 표시 여부를 제어합니다.

파일 도구 모음에는 스캔, 열기, 위로, 새 폴더, 인쇄, 복사, 잘라내기, 붙여넣기, 이름 변경, 휴지통으로 이동이 있습니다. 필터는 현재 목록을 좁히며 내용 검색과 별개입니다. 열 머리글을 클릭하면 정렬하고 항목을 두 번 클릭하면 엽니다.

4. 파일과 폴더 탐색

왼쪽 트리는 폴더 계층을 표시합니다. 화살표로 펼치고 폴더를 선택해 불러오며 위로를 눌러 상위 폴더로 이동합니다. 주소 표시줄과 기록 버튼도 사용할 수 있습니다.

열기는 선택 항목을 열고 연결 프로그램은 다른 앱을 선택합니다. 새로 고침(F5)은 현재 폴더와 관련 트리 노드를 다시 읽습니다. 새 폴더는 현재 위치에 중복되지 않는 이름으로 만듭니다. 이름 변경은 항목 이름을 바꿉니다. 끌어서 놓기로 지원되는 항목을 창 사이에서 이동하거나 복사합니다. 숨김 항목은 흐린 아이콘으로 표시됩니다.

파일 메뉴와 상황에 맞는 메뉴는 현재 선택에 적용 가능한 동작만 활성화합니다.

5. 즐겨찾기와 Windows 바로 가기

즐겨찾기에는 자주 쓰는 폴더를 저장합니다. 탐색 메뉴나 상황에 맞는 메뉴에서 추가하거나 제거합니다. 화살표 버튼이나 행 끌기로 순서를 바꿉니다.

바로 가기 영역에는 바탕 화면, 문서, 다운로드, 그림, 음악, 비디오, 휴지통을 표시할 수 있습니다. 전환 버튼으로 영역을 표시하거나 숨기고 목록을 오른쪽 클릭해 표시 항목을 선택합니다.

휴지통을 선택하면 삭제된 항목이 파일 목록에 표시됩니다. 메뉴에서 복원, 영구 삭제, 모두 비우기를 사용할 수 있습니다.

6. 문서 미리 보기

파일을 선택하면 오른쪽에 미리 표시합니다. 미리 보기는 일반 표시를, MS Office는 Office 변환 미리 보기를 별도로 켭니다. PDF 축소판과 배치, 확대/회전 가능한 래스터 이미지, 텍스트와 소스 코드, 내장 브라우저의 HTML, Office 문서를 지원합니다. 긴 텍스트는 응답 속도를 위해 일부만 표시할 수 있습니다.

이 버전에서는 Word와 Excel을 HTML로, PowerPoint를 PDF로 변환하며 Microsoft Office가 필요합니다. 탭을 고정하면 탐색 중 문서를 유지할 수 있습니다. 필요 없는 탭은 고정을 풀거나 닫습니다. 큰 문서는 설정된 페이지 수를 먼저 읽고 모두 불러오기로 나머지를 표시합니다.

Office 버전에 따라 변환 중 문서 창이 잠시 나타나거나 활성화될 수 있습니다.

7. PDF 편집

PDF와 페이지를 선택합니다. 선택 페이지를 왼쪽/오른쪽으로 돌리거나 전체 페이지를 회전합니다. 페이지 이동은 대상 위치를 묻고 페이지 제거는 편집 중인 문서에서 해당 페이지를 뺍니다. 파일에서 가져오기는 다른 PDF 페이지를, 스캐너에서 가져오기는 스캔 페이지를 추가합니다. 내보내기는 선택 페이지를 별도 PDF로 저장합니다.

페이지 너비 조정은 스캔한 페이지의 너비를 맞춥니다. 최적화는 옵션에 따라 이미지를 다시 압축합니다. 저장은 변경을 확정하고 다른 이름으로 저장은 별도 PDF를 만들며 취소는 디스크 버전으로 돌아갑니다.

최적화로 화질이 낮아질 수 있습니다. 파일 > 옵션에서 DPI와 컬러/흑백 압축을 신중히 선택하고 중요한 원본을 보관하십시오.

8. 파일 검색

검색 폴더는 시작 위치이며 하위 폴더 포함은 재귀 검색을 켭니다. 파일 마스크는 공백, 쉼표, 세미콜론으로 구분합니다(예: *.pdf *.txt). Word와 Excel은 *.doc* 및 *.xls* 패턴을 전환합니다.

이름과 내용 조건은 별도로 켤 수 있습니다. 둘 다 켜면 두 조건이 모두 일치해야 합니다. 텍스트는 일반 검색이고 정규식은 Python 호환 문법입니다. 대소문자 구분과 단어 전체가 결과를 제한합니다. 날짜와 크기의 시작/끝 값은 선택 사항입니다.

검색으로 시작하고 중지로 취소를 요청합니다. 결과를 두 번 클릭하면 주 창에서 파일을 선택하고 미리 보여 줍니다. 대화 상자는 기록, 크기, 위치, 열 너비를 기억합니다.

내용 추출은 텍스트/소스 코드, PDF 텍스트, 최신 Office 문서를 지원합니다. OCR 텍스트 층이 없는 스캔 PDF는 이미지 속 단어로 검색할 수 없습니다.

9. 파일 작업과 압축 파일

복사, 잘라내기, 휴지통 이동, 영구 삭제, 압축 파일에 추가 전에 하나 이상의 항목을 선택합니다. 붙여넣기는 현재 폴더를 대상으로 합니다. 단축키는 Ctrl+C, Ctrl+X, Ctrl+V입니다.

압축 파일에 추가는 선택한 파일/폴더를 묶습니다. 여기에 풀기는 현재 폴더에 풀고 다른 위치에 풀기는 대상 폴더를 만들거나 선택합니다. 지원 형식은 설치 도구와 설정에 따라 다릅니다.

영구 삭제는 휴지통을 거치지 않으며 DocExplorer에서 되돌릴 수 없습니다. 확인 전에 선택 항목과 경로를 검토하십시오.

10. 휴지통

Windows 바로 가기에서 휴지통을 엽니다. 삭제된 항목과 Windows가 제공하는 원래 메타데이터가 목록에 표시됩니다. 오른쪽 클릭 > 복원은 원래 폴더로 돌려놓습니다. 영구 삭제는 선택 항목을 지우고 모두 비우기는 휴지통 전체를 비웁니다.

원래 폴더가 없거나 접근이 거부되면 복원이 실패할 수 있습니다. 폴더를 다시 만들거나 필요한 권한을 확보한 뒤 다시 시도하십시오.

11. 스캔

파일 > 스캔 또는 스캐너 버튼을 선택합니다. Windows WIA 대화 상자에서 장치별 입력 소스, 색상, 해상도를 설정합니다.

여러 페이지 문서는 PDF, 이미지는 JPEG를 선택합니다. 여러 페이지를 켜면 하나의 PDF에 계속 추가합니다. 출력 파일명과 스캔 후 열기 여부를 정합니다. 같은 파일이 있으면 덮어쓰기, 번호가 붙은 복사본 만들기, 취소를 선택합니다.

WIA 호환 스캐너와 설치된 Windows 드라이버가 필요합니다.

12. 인쇄

파일을 선택하고 Ctrl+P 또는 파일 > 인쇄를 누릅니다. 프린터, 매수, 모든 페이지 또는 선택한 페이지를 지정합니다. 페이지 범위는 1,3-5 같은 표현을 허용합니다. 프린터 설정은 Windows 프린터 속성을 엽니다.

지원되는 PDF와 Office 문서에서 지정 페이지를 인쇄할 수 있습니다. 인쇄 여백과 배율은 드라이버 및 문서 앱이 결정합니다.

13. 옵션과 언어

옵션에는 언어, 미리 보기 제한과 동작, PDF 품질/DPI, 고급 컬러/흑백 인코딩, 스캔 기본값이 있습니다. 적용은 값을 저장합니다. 일부 문구는 즉시 바뀌지만 Windows 통합 구성 요소가 이전 언어를 유지하면 다시 시작하십시오.

지원 언어: 영어, 우크라이나어, 독일어, 프랑스어, 스페인어, 이탈리아어, 브라질 포르투갈어, 일본어, 한국어, 중국어 간체, 러시아어. 도움말은 선택한 인터페이스 언어로 열립니다.

14. 키보드 단축키

F1: 도움말. F5: 새로 고침. Ctrl+P: 선택/현재 문서 인쇄. Ctrl+C / Ctrl+X / Ctrl+V: 복사/잘라내기/붙여넣기. Ctrl+D: 휴지통으로 이동. Shift+Delete: 영구 삭제. Enter 또는 두 번 클릭: 열기/활성화. Ctrl+Z: 지원되는 임시 PDF 작업 실행 취소.

15. 문제 해결과 안전

미리 보기가 비어 있음: 미리 보기를 켭니다. Word/Excel/PowerPoint는 MS Office를 켜고 설치를 확인합니다. 큰 파일 변환을 기다린 뒤 다시 선택합니다. 외부 앱으로 열어 손상이나 잠금을 확인합니다.

내용 검색 결과 없음: 폴더, 마스크, 하위 폴더를 확인합니다. 이름과 내용을 모두 켜면 둘 다 일치해야 합니다. 날짜/크기 제한을 제거합니다. 스캔 이미지에는 OCR 텍스트가 필요합니다.

EXE의 아이콘이나 휴지통 동작이 다름: DocExplorer.spec으로 빌드하여 이미지, 번역, 설명서를 포함합니다. Windows 메타데이터는 계정, 언어, 권한에 따라 달라집니다. 외부 파일 작업 후 새로 고칩니다.

최적화, 영구 삭제, 대규모 PDF 편집 전에 백업하십시오. 다른 이름으로 저장을 써서 원본을 보존합니다. 접근/공유 오류가 나면 다른 앱의 파일을 닫습니다. PDF 쓰기나 압축 풀기를 중단하지 마십시오.
