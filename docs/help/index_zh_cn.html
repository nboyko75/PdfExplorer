目录

1. 关于 DocExplorer

DocExplorer 是面向文档查找、预览和处理的 Windows 文件管理器，集文件夹树、收藏夹、Windows 快捷入口、详细文件列表和预览窗格于一体，可直接编辑 PDF。

查看名称、类型、大小和修改时间；预览 PDF、图片、文本、HTML 和支持的 Office 文件；使用通配模式、正则表达式、日期和大小搜索名称及内容。PDF 修改暂存后可保存或取消。还支持复制、剪切、粘贴、重命名、删除、压缩、解压、扫描和打印。界面支持十一种语言。

Office 预览和打印需要兼容的 Microsoft Office 组件。扫描使用 Windows Image Acquisition（WIA）。解压能力取决于已安装的工具。

2. 开始使用

启动 DocExplorer 后，会恢复窗口大小、分隔条位置、语言、上次文件夹、收藏夹和多项对话框设置。

在树中选择文件夹，或在地址栏输入路径并按 Enter。在中间列表选择文件；启用预览且格式受支持时，右侧会显示内容。双击进入文件夹，或用关联的 Windows 应用打开文件。拖动分隔条调整窗格大小。在“文件 > 选项”设置语言和预览/PDF 参数。

PDF 页面修改暂存在内存中：“保存”写入磁盘，“取消”放弃修改。

3. 主窗口

“后退”和“前进”浏览位置历史。“搜索”打开文件搜索。“退出”处理未保存的 PDF 修改后关闭程序。地址栏接受文件或文件夹路径。“隐藏项目”控制隐藏项的显示。

文件工具栏提供扫描、打开、向上、新建文件夹、打印、复制、剪切、粘贴、重命名和移到回收站。“筛选”仅缩小当前列表，与内容搜索不同。单击列标题排序，双击项目打开。

4. 浏览文件和文件夹

左侧树显示文件夹层次。通过箭头展开节点，选择文件夹加载内容，用“向上”进入父文件夹。也可使用地址栏和历史按钮。

“打开”打开所选项目；“打开方式”选择其他应用。“刷新”（F5）重新加载当前文件夹和相关树节点。“新建文件夹”在当前位置使用不重复的名称创建文件夹。“重命名”更改名称。拖放可在窗格间移动或复制支持的项目。隐藏项显示为淡化图标。

文件菜单和右键菜单仅启用适用于当前选择的操作。

5. 收藏夹和 Windows 快捷入口

收藏夹保存常用文件夹。通过导航菜单或右键菜单添加、移除文件夹，用箭头按钮或拖动行改变顺序。

快捷入口区域可显示桌面、文档、下载、图片、音乐、视频和回收站。切换按钮控制该区域的显示；右键单击列表选择可见入口。

选择回收站后，文件列表显示已删除项目。右键菜单提供还原、永久删除和全部清空。

6. 预览文档

选择文件可在右侧预览。“预览”控制一般预览，“MS Office”单独控制 Office 转换预览。支持 PDF 缩略图和布局、可缩放旋转的位图、文本和源代码、内置浏览器中的 HTML 以及 Office 文档。过长文本可能截断显示以保持响应速度。

本版本将 Word、Excel 转成 HTML，将 PowerPoint 转成 PDF，需要 Microsoft Office。固定预览标签可在浏览时保留文档；不需要时取消固定或关闭。大型文档先加载设定页数，“全部加载”显示其余页面。

根据 Office 版本，转换时可能短暂出现或激活文档窗口。

7. 编辑 PDF

选择 PDF 和页面。可向左/右旋转选中页或旋转所有页面。“移动页面”要求指定目标位置；“删除页面”从暂存编辑版本中移除该页。从文件导入可添加另一个 PDF 的页面，从扫描仪导入可添加扫描页。导出将所选页写入独立 PDF。

“调整页面宽度”统一扫描页的宽度。“优化”按选项重新压缩内嵌图片。“保存”提交修改，“另存为”创建另一份 PDF，“取消”恢复磁盘版本。

优化可能降低画质。请在“文件 > 选项”谨慎设置 DPI 和彩色/黑白压缩，并保留重要原件。

8. 搜索文件

搜索文件夹指定起点；“包含子文件夹”启用递归搜索。文件模式用空格、逗号或分号分隔，例如 *.pdf *.txt。Word 和 Excel 切换 *.doc* 与 *.xls* 模式。

名称和内容条件可分别启用。两者同时启用时必须同时匹配。文本模式执行普通搜索，正则表达式模式使用 Python 兼容语法。“区分大小写”和“全词匹配”缩小结果。日期和大小的起止值是可选限制。

“搜索”开始操作，“停止”请求取消。双击结果可在主窗口选择并预览文件。对话框记住历史、大小、位置和列宽。

内容提取支持文本/源代码、PDF 文本及现代 Office 文档。没有 OCR 文本层的扫描 PDF 无法按图片中的文字搜索。

9. 文件操作与压缩包

在复制、剪切、移到回收站、永久删除或添加到压缩包前，选择一个或多个项目。粘贴目标为当前文件夹。快捷键为 Ctrl+C、Ctrl+X 和 Ctrl+V。

“添加到压缩包”打包所选文件/文件夹。“解压到此处”使用当前文件夹。“解压到”创建或选择目标文件夹。支持的格式取决于辅助工具和配置。

永久删除绕过回收站，无法在 DocExplorer 中撤销。确认前请核对所选项目和路径。

10. 回收站

从 Windows 快捷入口打开回收站。列表显示已删除项目及 Windows 提供的原始元数据。右键选择“还原”返回原文件夹。“永久删除”移除所选项目；“全部清空”清空整个回收站。

原文件夹不存在或权限不足时，还原可能失败。重新创建文件夹或取得适当权限后重试。

11. 扫描

选择“文件 > 扫描”或扫描仪按钮。Windows WIA 对话框控制设备相关的来源、颜色和分辨率设置。

多页文档选择 PDF，单张图片选择 JPEG。启用“多页”可连续添加到同一 PDF。指定输出文件名以及扫描后是否打开。文件已存在时，可覆盖、创建带编号的副本或取消。

需要兼容 WIA 的扫描仪及已安装的 Windows 驱动程序。

12. 打印

选择文件后按 Ctrl+P，或选择“文件 > 打印”。设置打印机、份数，以及全部页面或所选页面。页码范围支持 1,3-5 等格式。“打印机参数”打开 Windows 打印机属性。

支持的 PDF 和 Microsoft Office 文档可打印指定页面。可打印边距和缩放取决于打印驱动及文档应用。

13. 选项和语言

选项包括界面语言、预览限制和行为、PDF 优化质量/DPI、高级彩色/黑白编码以及扫描默认值。“应用”保存设置。部分标签立即更新；若 Windows 集成组件仍显示旧语言，请重新启动。

支持英语、乌克兰语、德语、法语、西班牙语、意大利语、巴西葡萄牙语、日语、韩语、简体中文和俄语。帮助使用当前界面语言打开。

14. 键盘快捷键

F1：帮助。F5：刷新。Ctrl+P：打印所选/当前文档。Ctrl+C / Ctrl+X / Ctrl+V：复制/剪切/粘贴。Ctrl+D：移到回收站。Shift+Delete：永久删除。Enter 或双击：打开/激活。Ctrl+Z：撤销支持的暂存 PDF 操作。

15. 故障排除与安全

预览空白：启用预览。对于 Word/Excel/PowerPoint，启用 MS Office 并确认已安装 Office。等待大文件转换后重新选择。用外部应用打开文件，检查损坏或锁定。

内容搜索无结果：检查文件夹、模式和子文件夹选项。名称与内容同时启用时必须都匹配。移除日期/大小限制重试。扫描图片需先获得 OCR 文本。

EXE 中图标或回收站行为不同：使用 DocExplorer.spec 构建，确保包含图片、翻译及手册。Windows 元数据随账户、语言和权限而异。外部文件操作后请刷新。

优化、永久删除或大量编辑 PDF 前先备份。用“另存为”保留原件。遇到访问/共享错误时关闭其他应用中的文件。不要中断 PDF 写入或压缩包解压。
